## 1. 摘要

本课题针对**平面闭环五杆机构**，用齿轮弹簧模块（gear-spring module, GSM）做重力补偿（gravity compensation / static balancing）。方法沿用 Nguyen、Lin 与 Kuo（2020）在 Delta 并联机器人上提出的“目标构型近似平衡”，但**不复现那台 Delta**。选择五杆，是因为设计逻辑相同——模块紧凑、使用普通压缩弹簧、在目标构型上匹配力矩——同时足够简单，能在本科周期内把理论推导、数值仿真和 3D 打印样机全部做完。

两个驱动摇杆各装一个 GSM。弹簧刚度 \(k_i\) 与安装角 \(\psi_i\) 按对称目标构型上“弹簧力矩抵消重力力矩”来确定。论文中单独设一章：把目标构型当作设计变量，按给定平面轨迹自动选取，而不是手工试几个角度。最后打印一台桌面样机，做准静态对比实验，测量有无 GSM 时驱动端要付出多少力。

预期成果是一条完整的“理论—仿真—实验”闭环，以及一条可陈述的设计准则：平面五杆的目标构型应按任务来选。

## 2. 研究背景与动机

重力补偿（又称静平衡）用弹簧或配重抵消机构自重引起的势能变化，从而减小电机力矩、降低能耗，并有利于人机物理交互时的安全性。

GSM 是带普通压缩弹簧的齿轮—滑块模块，结构紧凑，不依赖理想的零自由长度弹簧（ZFL spring）。该模块先用于平面串联臂，再用于 Delta 并联机器人（Nguyen et al., 2020）。Delta 方案在三条近端臂上各装一个 GSM。全工作空间的完美静平衡做不到，因此只在对称目标构型上强制剩余重力力矩为零，附近位形作近似，再用力矩下降率、能耗下降率等指标评价。

那篇 Delta 工作以数值为主，没有做成可测的空间样机。本科阶段若直接 3D 打印三腿 Delta（平行四边形、球铰、三套齿轮弹簧），对中误差和打印齿轮摩擦很容易把“省了多少平衡力”淹没。平面五杆可以避开这一风险，同时仍是闭环并联机构。

平面五转动副五杆机构有两个自由度。本课题采用的布置是：**固定杆在上方，两根驱动杆向下摇摆**，另外两根连杆闭合运动链，末端取在两连杆相连的铰点。它比 Delta 简单（两腿而非三腿，平面而非空间），但两腿耦合，重力力矩仍不是两个独立单杆问题。GSM 装在两个驱动关节上，与 Delta 装在近端臂上的想法一致。五杆没有 Delta 的三倍对称，因此重力力矩公式、目标构型的定义、甚至齿轮比是否仍取 2，都必须重推。**重推本身就是本课题的主体，而不是套用 Delta 公式。**

## 3. 研究空白

结合 2020 年 Delta+GSM 论文及同类工作，与本课题直接相关的空白有三点：

1. **该方法尚未在平面闭环五杆上走通。** 已有 GSM 工作面向串联臂和空间 Delta。上置机架的悬挂式五杆需要新的静力学模型和目标构型（例如末端在中线上的对称位形）。
2. **目标构型仍靠手工选取。** Delta 论文已表明不同任务偏好不同目标角，但只比较了少数离散值，没有按轨迹系统选角的规则。
3. **Delta+GSM 没有做成样机。** 带两套 GSM 的平面五杆，适合用来实测准静态下的力矩或拉力下降。

本课题针对这三点。变负载时如何改刚度、改安装角，只在讨论中涉及，不作为完整设计目标。

## 4. 研究目标、研究内容与科学问题

### 4.1 总目标

建立平面五杆机构的 GSM 重力补偿设计：包括解析定参、数值评价、按任务选择目标构型，以及简单的样机测试。

### 4.2 具体目标

1. 推导上置机架平面五杆两个驱动关节上的重力力矩，计入杆件自重和末端负载。
2. 在每个驱动摇杆上安装 GSM，在与 Delta 论文相同的实用假设下（弹簧初始为自由长度、齿轮臂远短于连杆）推导弹簧力矩。
3. 为五杆重新定义目标构型，求解弹簧刚度 \(k_i\) 与安装角 \(\psi_i\)；检查齿轮比 \(n_g=2\) 是否仍由力矩形式匹配得出。
4. 用力矩下降率（TRR）、平均/峰值力矩下降率、重力补偿密度（GCD），以及已知速度时的能耗下降率（ERR）评价工作空间与轨迹性能。
5. **（对应原方案一，作为正文一章）** 给定若干平面轨迹，把目标构型当作设计变量，用扫描或小型优化自动选取，并加上刚度上限、安装角范围、弹簧行程等约束；与手工目标角对比。
6. 3D 打印简单五杆与两套 GSM，测量有无弹簧时准静态驱动负担。

### 4.3 科学问题

- **问题一：** 用于 Delta 的目标构型近似方法，能否改写到平面五杆上，使两套 GSM 与普通压缩弹簧仍能给出可用的重力补偿？
- **问题二：** 对给定平面轨迹，自动选出的目标构型，是否在平均力矩、峰值力矩和能耗上优于常用的对称手工取值？
- **问题三：** 在 3D 打印样机上，摩擦和制造误差存在时，模型预测的平衡力下降是否仍然可测？

## 5. 研究范围

**纳入范围**

- 平面五杆，固定杆在上，两根摇摆驱动杆，每杆一套 GSM。
- 准静态设计；动力学仅用于事后按轨迹计算能耗下降率。
- 按任务选择目标构型（保持左右对称时，主要设计变量为一个目标角）。
- 一台简单 3D 打印样机及对比性准静态实验。

**不纳入范围**

- 复现或打印 Nguyen et al.（2020）中的空间 Delta。
- 完整的变负载自适应刚度机构（仅讨论）。
- 以手术或康复整机作为主对象。
- 高速动力学控制或工业级精密测量。

## 6. 研究方法与工作包

课题分四个工作包。工作包三即把“按轨迹自动选最优目标角”写入正文的那一章。

### 工作包一：机构定义与解析设计

- 确定五杆几何：机架长度、两摇杆长度、两连杆长度、质量参数与末端负载。
- 由末端位置 \((x,y)\) 求两摇杆转角 \((\theta_L,\theta_R)\) 的逆运动学。
- 由静力学求两驱动关节重力力矩 \(T_{w,L}\)、\(T_{w,R}\)（杆件质心与负载）。
- 在每个摇杆上建立 GSM 几何，得到弹簧力矩 \(T_{s,i}(\theta_i; k_i,\psi_i,n_g)\)。
- **用对称性定义目标构型：** 末端在竖直中线上，且 \(\theta_L=\theta_R=\Theta\)。这对应 Delta 论文中“三腿同角、动平台在竖直轴上”的条件，但必须按五杆重写。
- 在目标构型上令 \(T_s \approx T_w\)，解析（或半解析）求 \(k_i\)、\(\psi_i\)；写明假设（设计模型不计摩擦；\(n_g\) 由形式匹配选取或数值校核）。

### 工作包二：数值仿真

- 在可达工作空间上绘制 TRR，标出平衡区（TRR \(>0\)），并计算不同阈值下的 GCD。
- 至少仿真三类平面任务，例如：中线上的竖直提升；取放路径（侧向—抬起—横移—放下）；工作空间下部的曲线路径。
- 报告平均 TRR、峰值 TRR，以及 ERR（由末端速度经雅可比映射到摇杆角速度）。
- 对负载和 GSM 尺寸做敏感性分析，作为后文讨论变负载的铺垫。

### 工作包三：面向任务的目标构型选取（嵌入的方案一）

本章是在“把原文方法用于五杆”之上多出来的贡献，不是另开课题。

- 决策变量：对称情形下的目标角 \(\Theta\)。若时间允许，可放松对称，采用 \((\Theta_L,\Theta_R)\)。
- 目标函数：在给定轨迹上，对平均 TRR、峰值 TRR、ERR 加权最大化。
- 约束：\(k \le k_{\max}\)，\(\psi\) 在可安装范围内，弹簧力与行程不超过手册范围，\(\Theta\) 在可达区间内。
- 求解：先对 \(\Theta\) 做一维密扫描（论文图表清楚即可）；确有需要再上简单优化算法。
- 对比：手工目标（例如摇杆水平、工作空间中位、偏低位形）对自动选出的 \(\Theta\)。
- 预期结论：目标构型应按任务选取，而不是对所有运动固定取同一个角。

### 工作包四：样机与简单量测

- 桌面五杆三维建模：打印杆件；五个转动副用金属轴加滚动轴承；压缩弹簧用标准件；两套 GSM 的齿轮可打印或外购。
- 两种工况：拆掉 GSM 或使弹簧卸载（**未平衡**）；GSM 工作（**已平衡**）。
- 准静态实验（慢速，惯性可忽略）：
  - 用已知质量沿中线和一条取放路径缓慢移动或维持平衡；
  - 驱动负担至少用下列之一测量：已知力臂上的拉力计、悬挂质量静平衡、若使用减速电机则测电流反推力矩。
- 报告峰值与平均负担的下降，并讨论齿轮摩擦、齿隙、打印件质量误差造成的偏差。
- 安全：弹簧加防护、限位，不做高速实验。

**设计流程（对应 Delta 论文图 4，按五杆改写）：**

```
五杆尺寸 + GSM 几何 + 目标构型 Θ
        →  k、ψ
        →  工作空间指标（TRR、GCD）
        →  轨迹指标（平均 TRR、峰值 TRR、ERR）
        →  [工作包三] 按任务扫描 Θ → 得到新的 k、ψ
        →  样机：未平衡 vs 已平衡
```

## 11. 本开题明确不做的事

**不是**把 Nguyen et al.（2020）里的理论 Delta 或 FANUC 估计模型再做一遍。那篇文章是**方法模板**。新对象是平面五杆；新章节是按任务自动选目标构型；新证据是样机上的准静态对比测量。

## 13. 给指导教师的一段话

我想把 2020 年 Delta 论文中的 GSM 与目标构型方法当作模板，而不是把那台机器人重建一遍。毕设对象改为平面五杆：固定杆在上，两根摇摆驱动杆各装一个 GSM。我将重推静力学，沿用同一类力矩与能耗指标，增加一章按任务而不是按手工选择目标角，并 3D 打印一台小样机，做已平衡与未平衡的准静态对比。变负载自适应和空间 Delta 实物复现不纳入本课题范围。
