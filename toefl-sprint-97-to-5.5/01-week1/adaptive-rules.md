# 自适应与考场节奏（阅读 / 听力）

## 机制（必须内化）

```text
Module 1（相对固定）──表现好──► Module 2 Upper（高难，冲 5.5/6 几乎必需）
                 └──表现一般──► Module 2 Lower（难拿高分段）
```

- 只有 **阅读、听力** 自适应；写作、口语固定。  
- **进入 Module 2 后不能返回 Module 1。**  
- 模块内可用 Review 查漏改答案。

## Module 1 作战规则（本周养成）

1. **正确率 > 速度。** 宁可慢，不乱蒙连环错。  
2. **进 Module 2 前绝不留空。** 不确定题先标记，最后统一猜有依据的选项。  
3. **预留 Review 时间：** 阅读约 2–3 分钟；听力按界面剩余时间，优先查漏答。  
4. **基础/生活化题不轻视。** 自适应下这些题失分更容易把你送进 Lower。

## 阅读当日流程（约 70–80 min）

1. 限时完成 1 个 Module（或官方等量题）  
2. 对答案，错题归入 error-log（题型 + 主因）  
3. 重做错题：先不看解析，再对照  
4. 写下 1 条习惯：（例）「主旨题最后做」

## 听力当日流程（约 70–80 min）

1. 限时 Module  
2. 错题回听：标注「没听到」vs「听到但推错」  
3. 精听 1 段：只跟结构信号（观点 / 对比 / 因果 / 例子）  
4. 抽 2–3 句做 Listen and Repeat（听口联动）

## 笔记原则

- 不 verbatim 抄整句  
- 符号示例：`+` 支持，`vs` 对比，`→` 因果，`ex` 例子，`?` 问题  
- 一屏只记骨架，听完立刻看题

## 自检（每天结束勾）

- [ ] Module 1 无空题  
- [ ] Review 用过或明确「无需」  
- [ ] 错题已记主因  
- [ ] 知道自己今天若进 Upper 的把握（高/中/低）
