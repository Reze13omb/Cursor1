## 2. Write an Email（邮件）— 三套骨架

每套骨架本周至少实写 1 封。限时按考试界面（通常整段写作用时共享，练习时单封可先定 **7–9 分钟**）。

### 骨架 A：请求（Request）

```text
1) 称呼 + 一句话说明目的
2) 背景（1–2 句：为何需要）
3) 具体请求（时间/材料/动作，可分点）
4) 感谢 + 期待回复 + 落款
```

**语气：** 礼貌、直接、信息完整。

### 骨架 B：道歉 / 说明（Apology / Explanation）

```text
1) 目的：道歉或说明变更
2) 原因（简洁，不编长故事）
3) 补救方案（你能做什么）
4) 确认对方是否方便 + 感谢
```

### 骨架 C：建议 / 安排（Suggestion / Arrangement）

```text
1) 回应来信目的
2) 建议 1 + 简短理由
3) 建议 2（可选）或备选时间
4) 请对方确认 + 礼貌收尾
```

### 邮件过关检查（5.0→5.5）

- [ ] 收件人一看就懂你要他做什么  
- [ ] 关键信息（时间、地点、文件名等）不缺  
- [ ] 语气符合场景（教授/同学/行政）  
- [ ] 有开头称呼与结尾  
- [ ] 限时内写完；允许小错，但不达意 = 不及格

## 3. Academic Discussion（学术讨论）

旧托福能力可迁移。练习限时 **10 分钟** 左右（以官方时限为准再校准）。

### 固定结构（默写到肌肉记忆）

```text
句1  明确立场（同意/部分同意/不同意教授问题）
句2–3 理由 + 具体例子（校园/学习/社会均可，要具体）
句4  简短回应一位同学（补充 / 反驳一点），再收束
```

### 可用句框（换词即用，勿整段背长文）

**立场**

- I agree that … because …  
- I only partly agree: … is true, but …  

**例子**

- For example, when I …, I noticed that …  
- In many courses, students who … tend to …  

**回应同学**

- Unlike Student A, I think …  
- Student B makes a fair point about …; however, …  

### 过关检查

- [ ] 首句有立场  
- [ ] 有一个可感知的具体例子  
- [ ] 提到同学观点（哪怕一句）  
- [ ] 没写到一半超时  
- [ ] 清晰完整 > 高级词堆砌
