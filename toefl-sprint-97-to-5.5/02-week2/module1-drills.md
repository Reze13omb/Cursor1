# Module 1 正确率专项（阅读 / 听力）

冲 5.5/6 的前提：Module 1 少送分，才能进 Upper Module 2。

## 阅读 Module 1 协议

### 做题中

1. 先读题干关键词，再回文定位（主旨题可放后）  
2. 每题上限心理时钟：卡住超过合理时间 → 标记，继续，末尾 Review  
3. 排除法：先删与原文直接矛盾的选项  
4. **提交 Module 前：** Review 漏答 + 所有标记题  

### 错后分类（强制）

| 代码 | 含义 | 次日动作 |
|------|------|----------|
| LOC | 定位错段落/句子 | 只练「题干→原句」10 题 |
| VOC | 词汇/填空语义 | 错词进本，近义对比 |
| INF | 过度推理 | 写「原文哪句支持」 |
| TIME | 赶时间蒙的 | 加 Review 预留，减纠结 |

## 听力 Module 1 协议

### 做题中

1. 开篇 10 秒定场景（谁、什么问题）  
2. 笔记只记：观点、对比、因果、例子、态度变化  
3. 选择题先预测「可能问什么」再看选项  
4. 生活化/通知类题：**数字、时间、要求** 优先记  

### 错后二分

- **MISS：** 回听时才发现关键句 → 练「信号词后 5 秒」精听  
- **LOGIC：** 听到了但选错 → 写「选项为何与原句冲突」  

### 精听附加（每天 1 段）

1. 盲听记骨架  
2. 对照原文补漏  
3. 抽 2–3 句复述（服务口语）

## 「进 Upper」自评标准（主观但有用）

| 自评 | 条件 |
|------|------|
| H | 无空题；难题有依据；低级错 ≤1 |
| M | 无空题；有 2–3 题纯蒙 |
| L | 有空题或基础题连续错 |

连续两天 L → 次日该科双 Module1，砍扩展阅读。
