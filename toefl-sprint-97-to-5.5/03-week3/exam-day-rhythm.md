# 考试日节奏彩排

Week 3 起，每次全真都按「准考试日」作息，减少 Week 4 / 正式考试的新鲜感压力。

## 时间表模板（按你实际开考时间改）

假设开考 **10:00**：

| 时钟 | 行动 |
|------|------|
| 07:30 | 起床、早餐（清淡、熟悉的食物） |
| 08:15 | 轻度活动；不刷题 |
| 08:45 | 造句 5 题 + 复述 3 句开嗓（计时） |
| 09:15 | 出发/登录准备；检查证件与设备 |
| 09:45 | 就位；深呼吸；默念 Module1 规则 |
| 10:00 | 开考：读→听→写→说 |
| 结束后 | 不立刻对答案纠结；按 SOP 休息再复盘 |

## 能量管理

- 听力前可小口喝水（按考场规则）  
- 写作开始前 10 秒：默写邮件目的句结构  
- 口语前：咬肌放松，第一题允许不完美，保节奏  

## 崩盘预案（事先写好）

| 情况 | 立刻动作 |
|------|----------|
| Module1 连续两题不会 | 标记跳过，保其他题，末尾回改 |
| 造句卡住 | 选最通顺语序，不空题 |
| 邮件脑子空白 | 先写目的句+三条 bullet 再扩 |
| 复述漏半句 | 不重来，接下句 |
| Interview 超时焦虑 | 例子缩短，保证收尾一词 |
