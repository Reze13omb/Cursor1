# Week 4：模拟冲刺 + 稳定发挥

**目标产出：** 3–4 次全真；只修高频错点；睡眠与手感优先于学新技巧。

## 本周铁律

1. **不学新大招、不换新模板体系**  
2. 错题本周总结的 **Top 3** 以外的问题，一律记录但不展开打  
3. 全真质量 > 全真数量；累了就减量，不硬刚第二套  
4. 主目标仍是 **总分 5.5**；仅当四科已稳在 5.5 档才盯 6  

## 本周成功标准

- [ ] 全真 ≥3 次（D22 / D24 / D26，可选 D27 半套）  
- [ ] 每日睡眠充足（宁少刷题）  
- [ ] 高频错点修复卡完成  
- [ ] 考试清单勾完  
- [ ] 心态：熟悉感 > 焦虑感
