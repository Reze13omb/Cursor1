# 正式考试清单

考前一晚与当天早晨勾选。

## 行政与物品

- [ ] 确认考试时间、时区、到达/登录提前量  
- [ ] 身份证件在有效期内且符合 ETS 要求  
- [ ] 报名确认信 / 预约信息可查  
- [ ] 家考：系统检测通过；房间布置合规  
- [ ] 考点考：路线、交通、备用方案  
- [ ] 眼镜、允许的衣物、清水（按规则）  

## 学业准备（轻量）

- [ ] W4c 的三条默念已定稿  
- [ ] 崩盘预案已复习（见 Week3 exam-day-rhythm）  
- [ ] 不带未消化的新材料进考场  
- [ ] 写作骨架：请求/道歉/建议 能默写结构  
- [ ] Interview：观点→理由→例子 能空口报时  

## 身体与作息

- [ ] 考前两晚睡眠达标  
- [ ] 早餐计划确定（熟悉食物）  
- [ ] 不尝试新咖啡因剂量  
- [ ] 眼睛/耳朵疲劳管理（少刷手机）  

## 考后

- [ ] 知道出分大致时间  
- [ ] 过渡期成绩单含 1–6 与可比 0–120，按院校要求送分  
- [ ] 无论结果，先休息；需要重考再开下一循环  

## 考试日当日（精简）

```text
起床 → 早餐 → 5题造句+3句复述 → 出发/登录 → 默念3条 → 开考
```
