# 新托福一个月冲刺计划（97 → 5.5/6）

旧托福 **97**（约新制 **5.0**）→ 主目标总分 **5.5**，冲刺上限 **6**。

新制总分 = 四科平均后四舍五入到 0.5。**偏科会被平均分拖死**——每天追四科均衡，不追单科虚高。

## 分数锚点（官方区间粗标）

| 新制 | 约旧制总分 | CEFR |
|------|------------|------|
| 5.0 | 95+ | C1 |
| **5.5** | **107+** | C1 |
| 6.0 | 114+ | C2 |

冲 5.5 的安全组合示例：`5.5 + 5.5 + 5.0 + 5.0 → 平均 5.25 → 总分 5.5`。

## 默认时间假设

- 每天有效学习 **4–6 小时**（模板按 5 小时写）
- 旧分常见画像：读/听相对强，说/写相对弱 → 时间倾斜输出科
- 若分项相反，把弱科时间对调即可
