# 错题本（按题型）

一条错题一行。每周日把「同因重复 ≥3 次」的类型升为下周专项。

## 使用规则

1. 当天题目当天记，不隔夜。  
2. 原因只选一类主因（定位 / 词汇 / 推理 / 未听清 / 语法 / 时间 / 其他）。  
3. 订正栏写「下次具体动作」，不写空话（坏例子：「细心」；好例子：「先划题干关键词再回文」）。
