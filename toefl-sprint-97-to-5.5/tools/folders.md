# 文件夹约定

在本地（或云盘）建三个目录，路径自定，命名建议：

```
toefl-work/
  错题/          # 可放截图、导出；文字版用 tools/error-log.md
  口语录音/      # 文件名：YYYYMMDD-interview-01.m4a 等
  写作终稿/      # 邮件与讨论的「过关版」，不是初稿堆
```

## 口语录音命名

`YYYYMMDD-repeat-NN.ext` — Listen and Repeat  
`YYYYMMDD-interview-主题.ext` — Interview  

回听时只盯：**卡顿、语法重复错误、内容空**。

## 写作终稿标准

只有同时满足才移入「终稿」：

1. 限时内完成  
2. 目的/立场清晰  
3. 对照 [../01-week1/writing-templates.md](../01-week1/writing-templates.md) 结构完整  
4. 语法大错 ≤2（邮件/讨论）；造句另计正确率  

每周至少留 2 篇邮件 + 2 篇讨论终稿，供弱日对照，不背范文。
